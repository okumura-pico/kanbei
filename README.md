# 🧠 Kanbei — Issue-Driven AI Development

**Kanbei** is a multi-agent AI system that turns GitHub Issues into fully implemented, tested, and production-ready software.

Inspired by the legendary strategist *Kuroda Kanbei*, this project acts as your **AI right-hand problem solver**—an intelligent system that listens, plans, builds, and delivers.

---

## ✨ What It Does

Kanbei orchestrates a team of AI agents to execute the entire software development lifecycle:

1. **Requirement Gathering**
   - Interacts with humans via GitHub Issues
   - Clarifies goals, constraints, and expectations

2. **Specification Design**
   - Translates conversations into structured specifications
   - Defines scope, interfaces, and acceptance criteria

3. **Architecture Planning**
   - Designs system architecture
   - Chooses technologies and patterns

4. **Implementation**
   - Generates production-ready code
   - Follows repository conventions

5. **Testing & Validation**
   - Writes and executes tests
   - Ensures correctness and completeness

---

## 🧩 How It Works

Kanbei operates through **GitHub Issues as the interface layer**.

- Humans → create Issues
- Agents → read, respond, and collaborate through Issues
- Workflows → emerge as structured conversations

```
Human → Issue
        ↓
   AI Agents (multi-role)
        ↓
Spec → Architecture → Code → Tests
        ↓
 Pull Requests / Updates
```

---

## 🤖 Agent Roles

Kanbei is composed of specialized AI agents:

- **Listener Agent**  
  Understands requirements from Issue discussions

- **Spec Agent**  
  Formalizes requirements into clear specifications

- **Architect Agent**  
  Designs system structure and technical approach

- **Builder Agent**  
  Implements features and writes code

- **Tester Agent**  
  Ensures quality through testing and validation

Each agent collaborates asynchronously via GitHub Issues.
